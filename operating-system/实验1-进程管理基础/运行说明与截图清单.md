## 2. 任务1 进程基本信息查看

```bash
ps -aux | head -20                                   # 截图 1-1
ps -aux | grep -v grep | grep bash                   # 结合截图 1-1
ps -p $$ -o pid,ppid,stat,%cpu,%mem,cmd              # 当前 shell 的信息

pstree -p | head -30                                 # 截图 1-2
pstree -p $$                                         # 以当前 shell 为根的子树

top                                                  # 截图 1-3（按 q 退出）
# 建议同时截一张：top -b -n 1 | head -20

./process_info                                       # 截图 1-4：程序立即打印身份信息后退出
echo $$                                              # 当前 shell 的 PID，应与程序输出的 PPID 一致
id                                                   # 记录 UID/GID，供报告填写
```

## 3. 任务2 生命周期与状态转换

```bash
./process_lifecycle                                  # 前台运行，记下打印的 PID
# 立刻在另一个终端执行（15 秒的 sleep 期间）：
ps -p <PID> -o pid,ppid,stat,cmd                     # 截图 2-1：STAT 应为 S（可中断睡眠）

# sleep 结束后是约 9 秒的计数阶段（忙等待），时间充裕，再执行一次：
ps -p <PID> -o pid,ppid,stat,cmd                     # 截图 2-2：STAT 应为 R（运行/就绪）

echo $?                                              # 截图 2-3：正常终止退出码 0

./crash_demo ; echo $?                               # 截图 2-4：段错误(核心已转储)，退出码 139
```

进阶（可选）：运行中在另一个终端执行 `kill -9 <PID>`，再用 `echo $?` 查看被信号终止的退出码 137。
